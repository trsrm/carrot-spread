# Inbox

Human-owned capture zone organized by month to minimize filing decisions.

Use month folders:

```text
00-inbox/YYYY-MM/
```

Examples:

- `00-inbox/2026-05/`
- `00-inbox/2026-06/`

Drop notes, documents, web clips, transcripts, images, and imports into the current month folder. Agents classify and preserve raw material into `10-notes/` later.

Agents may copy or move processed items only when explicitly following the inbox workflow. Raw inbox material should not be deleted.
