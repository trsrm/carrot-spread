# Source

Preserved raw material lives here.

Do not replace raw source files with summaries. Processed knowledge belongs in `20-knowledge/`, `30-projects/`, or `40-systems/`.

## Naming

- Use short descriptive kebab-case filenames, for example `recipes/bbq-ribs.md`.
- Do not add leading date prefixes such as `2026-05-07-bbq-ribs.md`.
- Preserve capture/import dates in frontmatter, inbox processed markers, and `20-knowledge/log.md` instead of in source filenames.
- If two sources would have the same name, add a meaningful qualifier to the filename.

The starting source folders are practical defaults, not a fixed taxonomy. Agents may add new source folders when a recurring source type or sensitive area needs a clearer home.
