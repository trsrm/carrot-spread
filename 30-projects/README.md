# Projects

Bounded active efforts live here. A project can be personal, home-related, work-related, technical, creative, research-oriented, administrative, or experimental.

Use `_template/` when creating a new project workspace. The base template should work for most projects without assuming a sales, software, or work context.

Agents may add specialized templates later when a repeated project type needs one, such as software development, job search, client work, research, or travel.
