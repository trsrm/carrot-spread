# Project Template

This is the generic base template for any bounded effort.

Use it for:

- home projects
- personal administration
- work efforts
- software development
- research
- creative projects
- experiments
- pet projects

Agents may create specialized templates only when repeated projects show a real pattern that the generic template does not serve well.

Good specialized template candidates:

- `software-development`
- `research`
- `travel`

Do not create a specialized template for a one-off project.
