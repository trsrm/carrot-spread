# Systems

Reusable workflows, checklists, templates, decision frameworks, and other human/system operating methods live here.

The starting subfolders are practical defaults, not a fixed taxonomy:

- [workflows](workflows/index.md)
- [prompts](prompts/index.md)
- [checklists](checklists/index.md)
- [decision-frameworks](decision-frameworks/index.md)
- [templates](templates/index.md)

Agents may create new subfolders when a reusable operating asset does not fit these buckets or when a bucket becomes too broad.

Good future candidates might include:

- `automation/`
- `playbooks/`
- `review-routines/`
- `import-pipelines/`
- `evaluation/`

Use plain, lowercase folder names. Prefer reusing an existing folder until repeated use shows that a new folder would make the system easier to navigate.
