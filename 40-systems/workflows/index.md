# Workflows

Reusable workflows live here only when they are real operating routines worth preserving.

Do not create a workflow for every action. Create one only when the process:

- may recur often,
- has meaningful steps,
- benefits from consistency,
- prevents mistakes,
- or helps you/human remember how is something done.
